📸 Step 1: Rename Your Photos

You have several WhatsApp images in your images/ folder. Rename them to match the website's expected names:

New Filename Purpose Used On Page
sulekha-hero.jpg Main profile/hero image (250×250px circle) Homepage Hero
sulekha-professional.jpg Professional/career photo Career Page
sulekha-travel.jpg Travel or casual photo Homepage Gallery
sulekha-family.jpg Family or warm moment Homepage Gallery & Family Page
sulekha-portrait.jpg Close-up portrait photo Tribute Page
sulekha-temple.jpg Temple or spiritual location Hobbies Page Gallery
sulekha-beach.jpg Beach or water location Hobbies Page Gallery
sulekha-hills.jpg Hill station or mountain Hobbies Page Gallery
sulekha-candid.jpg Candid moment Hobbies Page Section
sulekha-smile.jpg Smiling/warm portrait Family Page

How to Rename:

Windows:

  1. Right-click the image file
  2. Select "Rename"
  3. Type the new name from the table above
  4. Press Enter

Mac:

  1. Right-click the image file
  2. Select "Rename"
  3. Type the new name
  4. Press Return

🚀 Step 2: Run the Local Server

Option A: Python (Easiest) ⭐

Open Terminal/Command Prompt in the sulekha folder and run:

python3 -m http.server 8000

Then visit: http://localhost:8000

Option B: Node.js (NPX Serve)

Run:

npx serve

Then visit the URL shown (usually http://localhost:3000)

Option C: VS Code Live Server

  1. Install "Live Server" extension
  2. Right-click index.html
  3. Select "Open with Live Server"
  4. Browser opens automatically

✅ Step 3: Preview & Test

  1. Open your browser to the local address (http://localhost:8000 or similar)
  2. Click through all pages to verify everything works
  3. Check that your renamed photos appear in the right places
  4. Use the contact form to test functionality

📝 Quick Troubleshooting

❓ Photos not showing?

  • Check file names match exactly (capitalization matters on Mac/Linux)
  • Verify photos are in the images/ folder
  • Refresh browser (Ctrl+R or Cmd+R)

❓ Server won't start?

  • Make sure you're in the correct folder
  • Try a different option (A, B, or C)
  • Install Python if you don't have it

❓ Want to customize text?

  • Edit any .html file with a text editor
  • Change colors in css/style.css
  • Refresh browser to see changes
