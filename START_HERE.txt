    🚀 GETTING STARTED IN 3 STEPS
================================================================================

STEP 1: Add Your Photos
  └─ Rename your photos to:
     ✓ sulekha-hero.jpg (main profile image)
     ✓ sulekha-professional.jpg (career photo)
     ✓ sulekha-travel.jpg (casual/travel photo)
     ✓ sulekha-family.jpg (family moment)
     ✓ sulekha-portrait.jpg (close-up portrait)
     ✓ sulekha-temple.jpg (temple/spiritual)
     ✓ sulekha-beach.jpg (beach photo)
     ✓ sulekha-hills.jpg (hill station)
     ✓ sulekha-candid.jpg (candid moment)
     ✓ sulekha-smile.jpg (smiling portrait)
  
  └─ Place all photos in the images/ folder

STEP 2: Start Local Server
  
  Windows:
    • Double-click start.bat
    • Or: Open Command Prompt, navigate to folder, run:
      python3 -m http.server 8000
  
  Mac/Linux:
    • Open Terminal, navigate to folder, run:
      bash start.sh
    • Or: python3 -m http.server 8000
  
  VS Code Users:
    • Install "Live Server" extension
    • Right-click index.html → "Open with Live Server"

STEP 3: Visit Your Website
  
  • Open browser to: http://localhost:8000
  • Browse all pages
  • Test the contact form
  • Share with family and friends!

================================================================================
    ❓ TROUBLESHOOTING
================================================================================

Photos not showing?
  □ Check file names match exactly (case-sensitive on Mac/Linux)
  □ Verify photos are in images/ folder
  □ Refresh browser (Ctrl+R or Cmd+R)

Server won't start?
  □ Ensure Python is installed (python3 --version)
  □ Navigate to correct folder in terminal
  □ Try different startup method

Links not working?
  □ Verify HTML files are in root folder
  □ Check spelling in href attributes
  □ Refresh browser

Styling looks wrong?
  □ Clear browser cache (Ctrl+Shift+Delete)
  □ Try different browser
  □ Check css/style.css exists in css/ folder
